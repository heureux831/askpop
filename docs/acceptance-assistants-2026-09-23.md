# 0.2.0 多模型与多助手验收

日期：2026-09-23。环境：本机 macOS、Apple Silicon、Electron 33.4.11。

## 完成范围

- 模型管理独立维护配置名称、供应商、模型 ID、API 地址、API Key；支持多个模型和独立加密 Key。
- 助手管理独立维护名称、图标、选用模型和系统提示词；支持多个助手、搜索和提示词模板。
- 对话标题栏提供助手选择器，切换时停止旧请求并清空旧会话上下文。
- 新设置采用导航／列表／详情三列布局，支持浅色、深色、跟随系统，以及未保存提醒、引用删除保护。
- 旧配置自动兼容为默认模型与日常助手，首次写入新格式备份旧 JSON，原加密 Key 保留可用。
- 顶部空白区域与中央把手可拖动；交互按钮不触发拖动。

## 实际验收证据

### 原生拖动

使用原生 UI 自动化操作真正的 Electron 窗口，测试配置位于独立临时目录。操作前后读取 BrowserWindow.getBounds()，不是只验证 CSS 或发送 IPC。

| 操作 | 操作前 x,y | 操作后 x,y | 窗口尺寸 |
| --- | --- | --- | --- |
| 顶部把手拖向右下 | 400,180 | 546,263 | 600×480 |
| 再向左下拖动 | 546,263 | 462,306 | 600×480 |

两次均收到拖动结束事件，松开后位置保持不变。随后点击助手按钮，正确展开日常助手、代码搭档、写作编辑菜单。拖动采用屏幕坐标差值，主进程检查事件来源并忽略非有限坐标；松开、取消、失焦或超时结束拖动。
