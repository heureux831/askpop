# 0.4.0 服务商工作台与快捷任务验收

## 功能

- 12 个内置服务商预设及本地 SVG 标志，可添加自定义连接或同一服务商的另一个账号。
- 服务商集中维护地址、接口类型、加密 API Key；下挂多个模型，每个模型配置 API ID、显示名称和温度。显示名称默认跟随 API ID，温度留空不发送参数。
- 助手模型选择器按服务商分组，System Prompt 独立配置。
- 快捷任务可增删、编辑标题/说明/图标/提示词、上下排序。后端将任务提示词追加到助手 System Prompt 后，每轮保留；不改写用户输入。
- 观察 OpenAI 兼容接口的 reasoning_content/reasoning 和 Anthropic thinking_delta。小字思考框正文固定 144px，独立滚动；用户向上滚动后暂停跟随；正文开始输出、停止或失败后自动折叠，可手动展开。答案复制和后续历史不包含思考文本。
- 旧思考参数保留兼容，界面暂不提供模式开关。修改模型 API ID 后恢复服务商默认行为。
- 旧配置迁移保留模型 ID、名称、助手引用和加密凭据槽，不合并不同账号。首次保存服务商结构备份 config.json.v3.bak。删除模型保留共享 Key；删除无引用的服务商清除对应凭据，包括旧格式回退文件。

## 验证

- TypeScript 检查通过。
- 完整 90 项单元测试通过；最后增加旧凭据清理用例后，相关配置/密钥测试 17 项通过，当前共 91 项测试。
- 真实 AI SDK + 模拟 HTTP 验证温度 0、温度留空、Anthropic 思考与答案流分离；SSE 测试覆盖逐字节 UTF-8、CRLF、心跳、取消与畸形事件。
- Electron 端到端通过：SVG 加载、多模型共享 Key、API ID 和显示名称分开、分组选模、任务增改与排序、提示词组合、温度、对话追问与错误、停止、主题、快捷键冲突及重启恢复。
- 思考区端到端：追加 60 行内容，高度不变；用户向上滚动后位置不变；主对话 scrollTop 不变；原生窗口 Bounds 不变；开始回答后折叠；重新展开可查看；下一轮不发送思考内容。
- 截图已检查，修正任务选中态、任务图标、下拉箭头及表单间距。长服务商/模型列表可滚动，保存按钮固定。

测试使用临时配置和本地模拟接口，没有改写用户真实配置或使用真实 Key 发起付费请求。预设供应商未逐一实网验证；各供应商支持的型号、权限和温度以其实际接口为准。
