# 助手工作台设计

依据 frontend-design Skill，面向随时唤起的 macOS 个人助手。

## 视觉计划

- 颜色：纸白 #FAFBFD、侧栏灰 #F0F3F7、墨蓝 #243247、辅助灰 #7B8798、交互蓝 #356DE8、成功绿 #368575。暗色使用独立层次，避免装饰渐变。
- 字体：macOS 系统字体 SF Pro／苹方；标题 24px，分区 15px，正文 13px，辅助 11–12px。模型 ID 单独使用系统等宽字体。
- 布局：左对齐。设置采用导航、对象列表、详情三列；快捷窗口顶部为可拖动标题栏，助手选择器放在明确的交互区。

```
设置： [导航 164] [搜索 + 助手/模型列表 242] [名称 / 模型 / 提示词 / 保存]
快捷： [品牌 + 可拖动留白] [助手选择] [设置]
       [问题输入 + 发送]
       [剪贴板 / 快捷功能 / 对话]
       [当前模型]                       [停止 / 复制 / 固定]
```

## 复核

不采用仪表盘统计卡片或营销页标题。模型是可复用连接，助手是基于连接的角色；列表到详情的结构直接体现这种关系。助手以不同的小型角色图标区分，不堆叠重复卡片。设置保存、切换助手、删除引用限制、空状态都显示明确反馈。

## 行为

- 一个模型保存名称、供应商、模型 ID、Base URL 和独立加密 Key。
- 一个助手保存名称、选用的模型和自定义提示词。多个助手可以使用同一个模型。
- 切换助手开始新对话，停止旧请求，避免不同提示词或模型混用历史。
- 旧配置按原内容迁移为“默认模型”和“日常助手”，保留原 Key。
- 被助手使用的模型不可直接删除，先更换助手模型。
- 设置详情独立保存；未保存时切换对象会提供放弃或返回编辑的选择。
- 拖动需要用原生鼠标实测窗口位置发生变化，不能只检查 CSS。
