AskPop · 唤问的首个公开版本：按下快捷键，随时提问。

### 下载

- **AskPop-0.2.0-arm64.dmg**：macOS Apple Silicon（M 系列芯片）安装包。
- **SHA256SUMS.txt**：安装包的 SHA-256 校验值。

打开 DMG，将 AskPop 拖入 Applications。当前版本未进行 Developer ID 签名或 Apple 公证，macOS 可能阻止首次启动；尚未验证其他电脑上的安装，不提供 Intel、Windows 或 Linux 安装包。

### 功能

- 全局快捷键唤起，可拖动和固定的桌面窗口。
- 独立模型管理：OpenAI、Anthropic、DeepSeek、自定义 OpenAI 兼容接口，每个配置独立保存 Key。
- 多助手管理：名称、图标、模型选择、系统提示词和模板。
- 对话顶部切换助手，自动停止旧请求并开始新会话。
- 流式对话、翻译、总结、解释、Markdown、剪贴板预览和回复复制。
- 全新设置工作台，浅色／深色／跟随系统外观。

### 升级

使用旧版 Quick Assistant 的用户请先退出旧应用，再启动 AskPop。原配置目录与加密 Key 保持兼容，旧配置自动映射为默认模型和日常助手。

### 验证

类型检查、63 项单元测试、真实 Electron 端到端测试和包内运行依赖检查通过。拖动已在本机原生窗口验收；接口测试使用隔离配置及本地 SSE 服务。聊天历史暂不持久化，暂不支持自动更新。
